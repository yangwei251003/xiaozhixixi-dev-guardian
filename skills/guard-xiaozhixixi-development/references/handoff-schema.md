# Handoff completeness

A usable `Progress.md` must contain:

- completed stages and verified deliverables;
- test/build commands with observed results;
- architecture and product decisions that must not be rediscovered;
- current Git branch, recent commits, and working-tree state;
- unfinished work, blockers, risks, and the next exact task;
- tools and Skills required for the next stage;
- a ready-to-paste new-window prompt;
- a reminder to read secrets only from the local `.env` without copying values.

Do not claim completion from file presence alone. Use test, build, browser, or artifact evidence.
